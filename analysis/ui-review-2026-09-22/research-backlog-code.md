## Review boundary and next validation

These are source-backed interaction candidates, not a request to restore Backlog.md's native UI. The Switchflow custom product should retain owner approvals, run admission and recovery policy while borrowing the narrowly useful contracts above. Before a change, render a disposable Switchflow fixture that contains hidden empty statuses, 30+ tasks, active filters, cross-project/foreign records, a concurrent refresh, and a deliberately interrupted move. Verify pointer, keyboard, focus-return and narrow viewport behaviour against that fixture.
