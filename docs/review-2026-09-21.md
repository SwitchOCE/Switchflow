# Improvement review, 21 September 2026

This review examines the current maintainer build, its imported template, browser workspace, native Backlog fork and workflow contracts. Existing consumer projects were not upgraded. Version 0.5.1 contains the resulting compatible fixes.

## First improvement cycle

| Finding | Change and evidence |

## Independent critique and second cycle

The first cycle was committed as `39113d8` before independent review. The critic received exactly: "Review the current build of switchflow, and ruthlessly look for bugs, contradictions and issues. Do not fix them or alter files, merely report."

The critic reproduced two further defects without modifying files:

- **P1:** native Backlog timeout and malformed-response paths rejected callers before confirming child termination, releasing write admission while a previous writer could remain active.
- **P2:** fresh Intake runs received only unconsumed messages, so earlier owner answers could disappear after several clarification rounds.

The second cycle addresses those lifecycle and context-continuity failures. The native transport retains admission until child closure, and every fresh agent context receives the chronological owner history with current input identified separately. Long history uses a complete run-local snapshot instead of silent truncation.

Integration review also found that valid JSON values such as `null` could crash the native response handler before transport validation. Non-object replies now enter the same termination fence. The second-cycle integrated gate passed all 154 tests with zero failures or skips, plus fresh-import, documentation, rendered-skill and cleanup checks. New regressions cover three clarification rounds, restart and subsequent Planning, oversized history, delayed closure, unsuccessful kill attempts, concurrent callers and malformed reply shapes.
