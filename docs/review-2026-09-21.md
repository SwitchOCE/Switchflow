# Improvement review, 21 September 2026

This review examines the current maintainer build, its imported template, browser workspace, native Backlog fork and workflow contracts. Existing consumer projects were not upgraded. Version 0.5.1 contains the resulting compatible fixes.

## First improvement cycle

| Finding | Change and evidence |
| --- | --- |
| Import could write through linked ancestors, fail after partial installation, and leave retries blocked by its own output. | Preflight all destinations; stage files and exact-hash recovery metadata; use exclusive leaf installation and preserve concurrent changes during rollback. Regression cases cover file ancestors, junctions, late locked `.gitignore` failure, clean retry and interrupted-import fencing. |
| Invalid persisted process identifiers could release an uncertain agent run. | Invalid identifiers retain the explicit recovery fence. Control tests exercise negative, fractional and string PIDs. |
| Invalid UAT rows could cause a server exception. | Validate every row before reading its ID; reject malformed actions without changing acceptance state. |
| Shutdown errors could leave the HTTP listener or admission state stranded. | Close the listener even when session cleanup fails, reject new requests during shutdown, and preserve uncertain process ownership. |
| A completed task save could clear a newer draft; save-time navigation could replace milestone editing state. | Bind draft cleanup to the submitted snapshot, prevent conflicting navigation while saving, and ignore stale editor responses. |
| Milestone comparison loads and browser reloads could lose draft text. | Capture text typed during reads and restore persisted milestone state when mounting the workspace. |
| Nested Markdown fences could be mistaken for decision section headings. | Browser and native parsers track delimiter character, length and valid closing syntax. Compiled native API tests round-trip nested fence content. |
| Check timeout killed only the immediate process, allowing descendants to retain output pipes and prevent completion. | Terminate the owned process tree and validate timeout limits. A real child-process regression verifies descendant termination and a durable timeout result. |
| Documentation overstated task-lifecycle enforcement and described obsolete checkpoint transport. | State precisely what `doctor` proves; distinguish role obligations from enforced native transitions; document description-only updates. |
